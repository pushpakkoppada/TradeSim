# TradeSim 📈

A web-based stock market simulation platform that allows users to practice trading with virtual money in a risk-free environment.

TradeSim provides a realistic-style trading experience with simulated stock prices, interactive charts, portfolio tracking, a leaderboard, and financial education resources.

---

## 🚀 Project Overview

TradeSim is designed to help beginners understand how financial markets and stock trading work without using real money.

Users receive virtual funds and can simulate buying and selling stocks, monitor their portfolio, track returns, and compare their performance with other simulated traders.

The project focuses on combining an interactive user interface with trading logic, portfolio management, market visualization, and financial learning.

---

## ✨ Features

### 📊 Market Dashboard
- Overview of the user's virtual trading account
- Available virtual balance
- Portfolio value
- Total account value
- Overall return
- Live simulation indicator

### 📈 Stock Market Simulation
- Simulated stock prices
- Stock selection
- Interactive price charts
- Market price visualization
- Simulated market environment

### 💰 Virtual Trading
- Buy stocks using virtual money
- Sell stocks from the portfolio
- Select the quantity of stocks
- Automatic calculation of estimated order value
- Portfolio and balance updates after trades

### 💼 Portfolio
- View current holdings
- Track stock quantities
- Monitor investment values
- View simulated trading activity

### 🏆 Leaderboard
- Compare simulated trading performance
- Ranking system for traders
- Return and portfolio comparisons

### 📚 Financial Education
- Beginner-friendly financial education
- Learn important concepts before investing real money
- Educational cards covering fundamental market concepts

### 📱 Responsive Design
- Desktop-friendly dashboard
- Responsive layout for smaller screens
- Mobile navigation support
